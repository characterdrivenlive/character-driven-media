# Character Driven Studio — TEST booths (design version 1)

Broadcast Booth, Recording Booth and Editing Studio in the approved Production Studio design (Approved Version 1), running in the browser.

Real in this TEST: microphone input recorded clean (no echo cancelling, noise removal or automatic level), Web Audio mix with faders, MUTE and SOLO (SOLO affects headphones only), meters from real signal, four music decks and a looping Music Bed from local files, one On Air / Record state button (tap for Ready, hold 1.5 s to go live, hold to stop), WAV recording at 48 kHz / 24-bit (session mix plus a clean host track), and offline 24-bit WAV export with Glue Mix in the Editing Studio.

Not connected: station relay, guests, telephone, PartyLine, server storage, Ensemble mic models. These show "Not in TEST" or a dash.

Static files only. Serve the folder from any static host. Nothing here touches the live booths.
